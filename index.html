Atividades públicas

    
Aqui aparecem as atividades que foram publicadas. A privacidade é definida por atividade: todas as questões de uma atividade publicada entram no banco público.

    

      🌐 Como funciona: publicar uma atividade não envia dados para a internet sozinho. No GitHub Pages, o site lê o arquivo
      public-questions.json. Para que todos vejam as mesmas atividades, esse arquivo precisa ser atualizado no repositório.
    

    

      
      
    

    

    

  


  
  

    
Perfil

    
Um perfil simples, salvo neste navegador, para organizar quem está usando o SamQuiz.

    

      
👤 Dados do perfil

      
O nome é opcional, mas a senha é obrigatória para salvar o perfil. A senha é armazenada como hash quando o navegador oferece a API de criptografia; ela não é usada para enviar dados para um servidor.
